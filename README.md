# Alerta-de-Lixo
Esse protejo academico constitui em criar um código em utilizando a liguagem de programação Python que na nossa visão represente uma solução que ajudar as pessoas e que possa ser utilizada pelo mercado. 
E a minha ideia foi criar um código que simule aplicativo de alerta de lixo onde o usuário depois de fazer login, pode além de enviar emails para o governo para falar sobre o acumulo de lixo ele podera solicitar outros serviços relacionados há higiene das ruas.
